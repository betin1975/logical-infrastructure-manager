Onboard a server

Use the exact hostname returned by hostname -f.

Server details

1. Confirm the real hostname

Run this on the target server:

hostname -f

The result must match the hostname entered above.

2. Add the server to LIM

cd /opt/logical-infrastructure-manager
source .venv/bin/activate

python -m app.cli server add \
  {{ server_name or "SERVER_HOSTNAME" }} \
  {{ server_ip or "SERVER_IP" }} \
  --user {{ admin_user or "deployer" }}

3. Verify and trust the SSH host key

On the target server:

sudo ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub

Then on the LIM server, use only the SHA256:... portion:

python -m app.cli trust add \
  {{ server_name or "SERVER_HOSTNAME" }} \
  --fingerprint '{{ fingerprint or "SHA256:PASTE_EXACT_FINGERPRINT" }}'

4. Copy the bootstrap bundle

cd /opt/logical-infrastructure-manager

scp \
  ssh/monitor_ed25519.pub \
  app/bootstrap/artifacts/remote_health.py \
  lim-bootstrap-install.sh \
  {{ admin_user or "deployer" }}@{{ server_ip or "SERVER_IP" }}:/tmp/

5. Install manually on the target

ssh {{ admin_user or "deployer" }}@{{ server_ip or "SERVER_IP" }}

cd /tmp
chmod +x lim-bootstrap-install.sh
sudo ./lim-bootstrap-install.sh

Enter the sudo password directly on the target server.

6. Verify the restricted monitor account

cd /opt/logical-infrastructure-manager

ssh \
  -i ssh/monitor_ed25519 \
  -o IdentitiesOnly=yes \
  -o UserKnownHostsFile=runtime/data/known_hosts \
  -o StrictHostKeyChecking=yes \
  monitor@{{ server_ip or "SERVER_IP" }}

Expected: JSON output, then the connection closes. A PTY warning is normal.

7. Record bootstrap completion

python - <<'PY'
from app.composition import build_application_services

services = build_application_services()
server = services.inventory_service.resolve_server("{{ server_name or "SERVER_HOSTNAME" }}")
services.inventory_service.record_bootstrap_success(server.uuid)
print("Bootstrap recorded")
PY

8. Poll and verify

python -m app.cli poll {{ server_name or "SERVER_HOSTNAME" }}
python -m app.cli server show {{ server_name or "SERVER_HOSTNAME" }}

After the first successful CLI poll, the dashboard can use Poll now from the server detail page.

Success checklist

  • Server appears in inventory
  • SSH trust is marked trusted
  • Monitor account returns JSON
  • Bootstrap is recorded
  • Poll completes successfully
  • Latest observation appears in the dashboard
